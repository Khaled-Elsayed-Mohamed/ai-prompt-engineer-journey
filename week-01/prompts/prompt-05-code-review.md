# Prompt 05 — Code Review
**Day 2 · Role + Task + Format exercise**

## Before
```
Check my code for bugs
```

## After
```
You are a senior software engineer doing a code review.
Your job is to review the Python function below and identify any
bugs, edge cases, or performance issues. Format your response as
a numbered list. For each issue, state: what's wrong, why it
matters, and how to fix it.
```

## What changed
Defined the reviewer's seniority (sets the bar for the critique), expanded scope beyond bugs to edge cases and performance, and required a structured format with three elements per issue.
