# Prompt 02 — Email Fix
**Day 2 · Role + Task + Format exercise**

## Before
```
Fix my email
```

## After
```
You are a professional business writing coach.
Your job is to rewrite the email below so it sounds confident,
clear, and respectful. Keep the same meaning. Return only the
rewritten email — no explanation needed.
```

## What changed
Defined tone (confident, clear, respectful), added a constraint to preserve meaning, and removed the explanation — so the output is paste-ready.
