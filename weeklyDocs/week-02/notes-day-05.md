# 🔨 Day 5 — Friday · Build Day

## What You'll Do

**Goal:** Review your Day 4 system prompt. Get feedback (peer review or self-review). Refine based on what you learn.

---

## Self-Review Checklist

- [ ] Does the system prompt avoid vague language?
- [ ] Does it specify tone and behavioral expectations?
- [ ] Does it handle edge cases?
- [ ] Did your tests reveal any assumptions that weren't met?
- [ ] Is there a clearer way to phrase any instruction?

---

## Refinement Process

1. **Identify 2-3 things that didn't work perfectly** in Day 4's tests
2. **Rewrite those sections** of the system prompt
3. **Re-test with the same 5 inputs** to see if behavior improved
4. **Document what changed** and why

---

## What to Capture

- Before & after versions of your system prompt
- How the behavior changed between versions
- What's still imperfect (and why)
- What you learned about writing good system prompts

---

## Peer Review (Optional)

If you get feedback from someone:
- Note what they said
- Note what you agree with
- Note what you'll keep/change

This becomes part of your GitHub documentation.
