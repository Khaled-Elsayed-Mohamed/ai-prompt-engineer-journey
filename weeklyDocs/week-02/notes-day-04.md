# 🔨 Day 4 — Thursday · Build Day

## What You'll Build

**Goal:** Write a system prompt for a helpful customer support agent. Test it with 5 different user messages. Refine based on what breaks.

---

## Setup

### The Challenge
Build a system prompt that:
- Stays professional but friendly
- Handles off-topic requests (without being rude)
- Handles product-specific questions
- Handles edge cases (angry users, unclear requests)

### Your Process
1. Write an initial system prompt (15 min)
2. Test it with 5 diverse user messages (20 min)
3. Identify what broke or felt off (10 min)
4. Refine and re-test (20 min)

---

## Starter Template

```
You are a [role] customer support assistant for [product/service].
Your tone is [describe tone].
You should [key behavior 1], [key behavior 2], and [key behavior 3].
If the user asks about [edge case], respond by [what to do].
```

---

## Test Cases to Try

1. **Off-topic question:** "Explain what AI is"
2. **Vague product question:** "How does it work?"
3. **Bug report:** "Your app keeps crashing"
4. **Escalation:** "I want to speak to a human"
5. **Follow-up:** "Why did you say that?"

Save your results:
